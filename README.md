# Unity Roll-a-Ball Demo

A simple Unity project demonstrating basic game mechanics such as player movement, camera control, and object collection. This project is based on Unity's official **Roll-a-Ball** tutorial.

![Screenshot](screenshot.jpg)

---

## 🎮 Features
- Player-controlled rolling ball
- Collectible objects scattered across the play area
- Score tracking system
- Basic camera follow mechanics

---

## 🛠 Requirements
- Unity Hub
- Unity Editor (6.3 LTS or newer recommended)

---

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project in Unity Hub.
3. Load the game scene.
4. Press **Play** in the Unity Editor to start the demo.

---

## 🎯 Controls
- **W / A / S / D** or **Arrow Keys** → Move the ball
- **Esc** → Quit (in built version)

---

## 📂 Project Structure
- `Assets/Scenes` → Contains the main game scene
- `Assets/Scripts` → Player movement and game logic scripts
- `Assets/Prefabs` → Ball, collectibles, and environment prefabs
